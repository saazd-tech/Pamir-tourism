# Путешествия по Памиру

Небольшой русско-, англо- и таджикоязычный сайт-путеводитель по Памиру и административная панель для туристических объявлений. Проект использует обычные HTML, CSS и JavaScript, а также встроенный HTTP-сервер на Node.js.

## Возможности

- Страница-путеводитель с направлениями, местами, размещением, маршрутами и культурными материалами.
- Интерактивная карта мест Памира с поиском и фильтром по категориям. Для картографических тайлов используется OpenStreetMap; для их загрузки требуется интернет.
- Переключение русского, английского и таджикского языков.
- Административная панель для создания и просмотра объявлений.
- HTTP API для объявлений и гостиничных номеров.
- Сохранение объявлений в `listings.json` и гостиничных номеров в `hotels.json`. Если API объявлений недоступен, панель может сохранить объявление в локальном хранилище браузера.

## Требования

- Node.js 14 или новее.
- Современный браузер.

Внешние npm-пакеты для запуска проекта устанавливать не нужно.

## Запуск

Из корневой папки проекта выполните:

```bash
node server.js
```

Откройте в браузере:

- `http://localhost:3000/` — панель управления;
- `http://localhost:3000/new.html` — сайт-путеводитель.

Сервер использует порт `3000`. Остановить его можно сочетанием `Ctrl+C`.

## API

Все ответы API возвращаются в формате JSON.

| Метод | Путь | Назначение |
|---|---|---|
| `GET` | `/listings` | Получить объявления |
| `POST` | `/listings` | Добавить объявление с полями `places`, `gallery`, `articles`, `map` |
| `GET` | `/hotels` | Получить список гостиничных номеров |
| `GET` | `/hotels/:id` | Получить номер по числовому идентификатору |
| `POST` | `/hotels` | Добавить номер с полями `hotelName`, `roomType`, `pricePerNight`, `availabilityStatus` |

Для `POST`-запросов передавайте JSON с заголовком `Content-Type: application/json`. Данные сохраняются в JSON-файлы в корне проекта.

## Основные файлы и каталоги

- `main.html`, `app.css`, `app.js` — административная панель.
- `new.html`, `new.css`, `i18n.js`, `places.js`, `stays.js` — сайт-путеводитель, карта и языковые строки.
- `server.js` — HTTP-сервер и API.
- `hotels.json`, `listings.json` — данные API.
- `assets/`, `suraten_tj/` — изображения, значки и файлы карты.
- `aos-master/` — библиотека анимации AOS; её лицензия находится в `aos-master/LICENSE`.

Сервер предназначен для локального запуска и не включает аутентификацию для API. Перед публикацией в открытом доступе настройте защиту API и безопасное хранение данных.
